# Прогулка и дорожка — что осталось

Сделано: мир прогулки под прозрачным дневником, своя дорога, еда — подбираемыми предметами, беговая дорожка
подключается к телефону сама (CompanionDeviceManager / CoreBluetooth), шаги телефона (Health Connect / Core Motion)
вместе с дорожкой, итог прогулки репликой Зёрнышка, шагомер панелью справа, мир можно держать всегда,
корзинка с рассыпанием у сообщений, ответы галочкой и крестиком.

## Дорожка — довести

- [x] **Bluetooth без обходных путей.** Chrome даёт Web Bluetooth только безопасной странице (https или
      localhost), а страница с телефона — `http://<ip>:47800`. Сейчас работает только через
      `adb forward tcp:18800 tcp:47800` и `http://localhost:18800/`. Варианты: флаг Chrome
      `unsafely-treat-insecure-origin-as-secure` для адреса телефона или https на телефоне (проверить,
      даёт ли самоподписанный сертификат Bluetooth).
- [x] **Развести демо и дорожку.** `?walk` — панель настроек мира; демо — отдельный параметр.
      Сейчас `?walk` включает демо и к дорожке не подключается.
- [x] **Шаги телефона.** Шаги дня = шаги телефона + шаги дорожки; шаги телефона за время прогулок
      вычитаются (телефон в кармане на дорожке). Android — Health Connect, iOS — Core Motion
      (проверить на Mac). Разрешение — вопрос Зёрнышка в ленте приложения «Да/Нет» (ждёт решения).
- [x] **Цель шагов и рост.** Шаги дня — плашкой в ленте после записей; тап по ней — шит Зёрнышка с целью
      шагов и ростом (профиль). Рост из помощника цели запоминается; цель — и на странице, и в итоге прогулки.
