# План на будущее

## Модель на устройстве (LLM) — идеи

Источник: «Доставляем 584 МБ модель Gemma через Google Play» (apptractor.ru).
Модель доставляется через Play for On-device AI (AI packs поверх Play Asset Delivery),
запускается через LiteRT-LM. Только AAB, пак до 1,5 ГБ, режимы install-time / fast-follow / on-demand,
таргетинг по RAM/чипу. Нужна декларация foreground service в Play Console.

**Принцип:** цифры КБЖУ модель не выдаёт никогда — только «что это», «сколько» и формулировки.
Факты считает приложение, модель их пересказывает.

### 1. Живые реплики персонажей и пуши
- Ежедневные вопросы от персонажей, разнообразные пуши, разговоры под рацион конкретного человека
  (что ест, недобор/перебор БЖУ, серии дней, время приёмов).
- Сначала — банк реплик: тысячи шаблонов с подстановками, сгенерированных заранее сильной моделью
  на сервере; подбор по фактам рациона локально. Без скачивания модели, данные не уходят с телефона.
- Потом — опционально модель на устройстве (on-demand пак): ночью генерирует реплики, днём показываем готовое.
- Фильтр ответа модели: длина, стоп-слова, никаких цифр, которых не было во входе, никаких советов о здоровье.

### 2. Запасной разборщик свободного текста
- Когда `TextParser` не справился или низкий `confidence`: фраза → JSON `[{name, count, unit}]` →
  `ParsedSegment` → существующий поиск и `toGrams`.
- То же для текста с фото (OCR меню/состава) → `TextFoodResolver.resolve()`.
- Первый шаг: прототип с моделью через `adb push`, прогон 50–100 фраз, где текущий парсер ошибается;
  замер точности, задержки, памяти.

### 3. Вопросы к дневнику
- В ленте-диалоге человек спрашивает: «сколько белка я ел на прошлой неделе?», «когда последний раз ел рыбу?»,
  «в какие дни я перебираю?».
- Модель переводит вопрос в структурный запрос (период, нутриент, продукт, агрегат) из заранее
  заданного набора — свободный SQL не генерирует.
- Запрос выполняет приложение по Room; модель только формулирует ответ голосом персонажа из готовых цифр.
- Не понял вопрос — переспросить или предложить чипсы с похожими вопросами, а не угадывать.

### 4. Подсказки «что съесть, чтобы добрать»
- «Осталось 40 г белка — из того, что ты обычно ешь: творог 200 г или куриная грудка 150 г».
- Кандидаты — только из личной истории продуктов (частые, привычные для этого приёма и часа),
  граммы и КБЖУ считает приложение; модель выбирает формулировку, не цифры.
- Без медицинских советов и запретов; только «чем закрыть остаток».
- Тап по подсказке — сразу запись в дневник.

### 5. Модель поменьше
- Вместо Gemma 3 1B (584 МБ) — дообученная Gemma 3 270M на синтетике из нашего парсера и базы.
- Проверить русский: Gemma vs Qwen.
- Gemini Nano (ML Kit GenAI Prompt API) как первый уровень, где доступен; проверить русский.

### Риски
- Слабые телефоны (<6 ГБ RAM) — проверять память перед предложением скачать.
- Бета-библиотека, декларация foreground service + видео в Play Console.
- Лицензия Gemma (Prohibited Use Policy); у Qwen — Apache 2.0.
